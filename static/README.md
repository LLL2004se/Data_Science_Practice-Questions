# PolicyProbe - Static Version

This is a static HTML version of the PolicyProbe hackathon project that works with VS Code's Go Live extension.

## How to Use:

1. Open VS Code
2. Install the "Live Server" extension if you haven't already
3. Right-click on `static/index.html`
4. Select "Open with Live Server"

## Features:

- ✅ Complete insurance claim processing interface
- ✅ AI-powered decision making
- ✅ Real-time form validation
- ✅ Policy rule implementation
- ✅ Professional UI with animations
- ✅ Works without any build process

## Webhook URL:

The webhook endpoint would be:
```
https://your-domain.com/api/webhook/claims
```

## Test Cases:

Try these examples:
1. **Approved**: Age 35, dental cleaning, 8 months policy
2. **Rejected**: Age 46, knee surgery, 3 months policy
3. **Senior Benefits**: Age 70, general surgery, 2 years policy

The static version includes all the same logic as the React version but runs entirely in the browser without any build process required.
